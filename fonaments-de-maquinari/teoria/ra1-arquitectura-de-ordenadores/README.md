# RA1 – Arquitectura de ordenadores

## ¿Qué aprenderás en este RA?

Al terminar este bloque deberías poder explicar qué hace cada componente principal de un ordenador, distinguir memoria de almacenamiento, describir el recorrido de los datos y relacionar las características de CPU, buses y memorias con el rendimiento del equipo.

## Ruta de estudio recomendada

1. Introducción y arquitectura de Von Neumann
2. Microprocesadores
3. Buses de conexión
4. Memorias
5. Memoria caché L1, L2 y L3
6. Almacenamiento: HDD, SSD y NVMe

## Cómo estudiar este tema

* Primero comprende la función de cada componente; después memoriza nombres y características.
* Dibuja el recorrido de una instrucción: memoria → CPU → operaciones → resultado.
* Compara siempre conceptos parecidos: RAM frente a almacenamiento, núcleo frente a hilo, SATA frente a NVMe.
* Al acabar cada subpágina, intenta contestar las preguntas sin mirar los apuntes.
